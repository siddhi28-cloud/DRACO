Note for Reviewers / Judges

This project requires a Gemini API key to run locally. The key is loaded from a .env file which is intentionally excluded from this repository for security reasons. To run Draco yourself:
Generate your own free key from Google AI Studio.
Add it to a .env file as shown above.

Features
 Real-time local monitoring of files, network activity, and processes
 LLM-driven threat analysis with a senior-ethical-hacker persona
 Guardrailed decision-making via NeMo Guardrails — Draco can't go rogue
 Automated countermeasures in response to detected threats
 Full incident logging for transparency and review
